
Unload Pro is an Android app I designed and built after noticing an operational problem at work: managers didn't have an easy way to see whether a truck unload was on pace until the team was already falling behind.

The app tracks unload progress in real time, identifies bottlenecks and delays, projects completion time, and gives managers information they can use when deciding whether additional help is needed.

I designed and developed the application myself in Kotlin based on the actual workflow I was working in. Using the workflow contributed to roughly a **25% improvement in productivity**.

## What It Demonstrates

- Identifying an operational problem through firsthand experience
- Designing a practical solution around an existing workflow
- Turning operational data into useful information for decision-making
- Iterating on the system as new problems and bottlenecks became apparent
- Teaching myself the technical skills necessary to build the solution
